# Qoder 赛题项目 —— 主流程零第三方依赖
#
# 本文件刻意只有注释，不装任何包：
# 交付物的主功能（规则引擎 / 自检 / 常驻 HTTP 服务）只用 Python 标准库，
# 评测机上不需要 pip install、不需要联网，`python run.py` 直接可跑。
#
#     python run.py            # 自检：SELFCHECK PASS，退出码 0
#     python run.py --serve    # 常驻服务 -> http://127.0.0.1:8501

#
#     pip install -r requirements-ui.txt
#     streamlit run app.py
#
# 需要「真·seekdb 检索 + 审查历史落库」时，再装可选的内核依赖：
