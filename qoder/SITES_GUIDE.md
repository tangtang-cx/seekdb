# Qoder Sites 发布 · 逐步操作指南

> 官方依据：<https://docs.qoder.com/zh/qoder/sites>
> 目标：拿到一个**任何人可访问**的项目网站网址，并填进提测平台。

---

## 第 1 步：确认版本与入口

- 桌面端 **v0.3.3 以上**、CLI **v1.1.54 以上**才支持 Sites。
  在 Qoder 里输入 `/sites` 看是否有反应；没反应先升级。
- 三个入口任选其一（产物完全一致）：
  - **左侧栏「站点」→ 添加站点**（推荐，图形化）
  - 对话框输入 `/sites` + 你的需求
  - CLI：`qoder chat` → `/sites`

---

## 第 2 步：把项目交给 Qoder 生成站点

在 Sites 的输入框里，用下面这段话（**直接复制**）：

```text
用 /sites 把当前目录的 qoder/ 项目做成一个可交互的网站（个人作品展示站），
主题是「数据库代码审查助手（Qoder × seekdb）」。

要求：
1. 首页包含：项目简介、解决的问题、核心功能表、演示截图、运行说明、代码仓库链接、Qoder 账号 UID 位置；
2. 嵌入一个交互演示：左侧 SQL 输入框 + 「开始审查」按钮，右侧按 🔴阻断 / 🟠警告 / 🔵提示 三级输出审查结果，
   规则与 qoder/reviewer.py 里的 15 条规则一致（SELECT *、UPDATE 缺 WHERE、JOIN 缺 ON、
   LIKE '%x'、索引列被函数包裹、深分页 OFFSET、NOT IN 与 NULL、IN 列表过长、建表缺主键 等）；
3. 展示真实界面截图：screenshots/04-app-home.png 与 screenshots/05-app-review-results.png；
4. 写出运行说明：pip install -r requirements.txt && streamlit run app.py，
   并说明 seekdb 检索与审查记录落库的表结构；
5. 代码仓库链接指向 https://github.com/tangtang-cx/seekdb （分支 qoder）。
```

> 如果 Qoder 生成的站点不是你要的样子，继续在对话框里追加修改指令，它会就地改。
> 我们已经把成品放在 `qoder/site/index.html`（自带交互演示 + 截图 + 运行说明），
> 如果 Qoder 需要素材，直接让它引用这个文件即可。

---

## 第 3 步：发布

1. 在**最新预览**里检查内容、链接和交互是否符合预期；
2. 点站点面板右上角的**「发布」**，等状态变成「已发布」；
3. 打开发布详情查看**网站地址**，点「访问」确认线上页面正常。

> 预览和线上版本是分开的：改了之后**必须再点一次发布**才会更新线上。

---

## 第 4 步：设置访问范围（**最关键**）

1. 在站点列表或站点详情里点**「分享」→「更改访问范围」**；
2. 选 **「任何人都可访问」**；
3. 个人版会弹出确认 → 点**「允许公开访问」**；
4. 复制链接。

> ⚠️ **必须是个人版账号**：企业版 / Teams / Enterprise **不支持公开访问**
> （只有「仅自己 / 仅受邀用户 / 组织成员可访问」），评委会打不开。
> 官方原话：「企业版账号无法设置公开访问，请使用个人账号发布。」

---

## 第 5 步：验收自查（提测前必做）

| 检查项 | 怎么做 | 期望 |
| --- | --- | --- |
| 未登录可访问 | **无痕 / 隐身窗口**打开链接 | 页面正常显示 |
| 交互可用 | 在演示框里粘一段 SQL 点「开始审查」 | 出现三级结果 |
| 截图在页面上 | 滚到底看「界面实拍」 | 两张截图正常显示 |
| 链接是完整网址 | 从地址栏整段复制 | `https://<你的子域>.qoder.site`（或平台给的实际域名） |
| 仓库链接可点 | 点页面里的 GitHub 链接 | 打开我们的仓库 |
| 访问统计 | 站点 → **更多 → 访问统计** | 有访问次数、独立访客数据（截图作为「使用效果」材料） |

---

## 第 6 步：填进提测平台

| 字段 | 填什么 |
| --- | --- |
| 项目网站网址 | 第 4 步复制的链接 |
| 代码仓库地址 | `https://wzhaihqy:<你的 GitHub PAT>@github.com/tangtang-cx/seekdb.git` |
| 分支 | `qoder` |
| Commit | `qoder` 分支最新 commit 的 40 位 SHA（提测前用 `git ls-remote` 或仓库页面确认） |
| Qoder 账号 UID | **设置 → 个人资料 → 编辑** 里能看到（官方原文：「Qoder UID 可以在设置 → 个人资料 → 编辑中查看」） |
| 其余材料 | 运行说明、验证样例、Qoder 开发记录截图（见 [`DEVELOPMENT_LOG.md`](DEVELOPMENT_LOG.md)） |

---

## 备选路径：站点托管不了 Streamlit？

我们已提供 `qoder/site/index.html` —— **纯静态、零依赖、零构建**，自带：

- 浏览器内的 15 条规则交互演示（与 `reviewer.py` 同源）；
- 两张真实界面截图；
- seekdb 表结构与检索链路说明；
- 运行说明与仓库链接。

如果 Sites 只能托管静态页面，就让它发布这个目录（`qoder/site/`），
网站照样是「可访问 + 可交互 + 能看出技术结合 + 有截图」。
